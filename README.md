# Clima Cureña

Clima Cureña es una aplicación móvil que permitirá consultar las condiciones meteorológicas actuales y el pronóstico de diferentes comunidades cercanas a Unión del Toro, en Sarapiquí.

Las ubicaciones incluidas serán Unión del Toro, Tambor, Los Ángeles, Copalchí, Puerto Viejo, La Delia y Chaparrón. La aplicación también permitirá guardar ubicaciones favoritas para consultarlas posteriormente, incluso después de cerrarla.

## Tecnologías

- React Native
- Expo
- TypeScript
- Expo Router
- Open-Meteo API
- SQLite
- Context API

## Ejecución

Instalar las dependencias:

```bash
npm install
```

Iniciar la aplicación:

```bash
npx expo start
```
